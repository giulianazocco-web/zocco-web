# zocco.ar

Web de Giuliana Zocco. Se publica sola en Cloudflare Pages con cada cambio en este repositorio.

- Páginas: `index.html`, `sobre-mi/`, `cursos/estrategia-digital/`
- CTRL.G: cada entrada es un archivo en `ctrlg/posts/`. Se cargan desde el panel en app.pagescms.org
- Configuración del panel: `.pages.yml`
- Generador: Eleventy (`npm run build` → carpeta `_site`)
