# zocco.ar

Web estática (HTML + CSS), sin dependencias ni paso de compilación.

- `index.html` → inicio
- `sobre-mi/` → bio en tercera persona (para buscadores y prensa)
- `cursos/estrategia-digital/` → página del curso
- `llms.txt` → resumen para motores de IA
- `sitemap.xml` y `robots.txt` → para Google
- `assets/` → estilos, tipografía Newsreader (licencia OFL), imágenes y logo

Publicación: Cloudflare Pages conectado a este repositorio. Cada cambio que se sube acá se publica solo.
